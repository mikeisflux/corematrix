# Third-party models and environment maps

- `robot.glb` — "RobotExpressive" by Tomás Laulhé (Quaternius), CC0 1.0. Converted and
  modified by Don McCurdy for the three.js examples. https://quaternius.com
- `../hdri/warehouse.hdr` — "Empty Warehouse 01" from Poly Haven, CC0 1.0.
  https://polyhaven.com/a/empty_warehouse_01

Everything else in this folder (`avatar-*.glb`, `table*.glb`, `chair.glb`, `banner_stand.glb`,
`cabinet.glb`, `light.glb`) is generated by `npm run models` from `src/lib/hall/modelkit/`
and is part of this project. Replace any of them with your own `.glb` that keeps the same
node and material names and the scene picks it up with no code changes.
